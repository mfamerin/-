اصلاحات دینگی - Telegram Mini App v1
=====================================

این پروژه Backend، دیتابیس و Bot Token داخل کد ندارد.
فایل‌ها فقط HTML/CSS/JavaScript هستند و باید روی یک آدرس HTTPS عمومی قرار بگیرند.

ذخیره اطلاعات:
- در داخل Telegram از Telegram CloudStorage استفاده می‌شود.
- داده هر کاربر به صورت جداگانه برای همان Bot/User ذخیره می‌شود.
- اگر CloudStorage در کلاینت در دسترس نباشد، DeviceStorage و در آخر localStorage استفاده می‌شود.
- برنامه هیچ API برای ارسال نام یا اصلاحات به مالک ربات ندارد.

امکانات:
- ثبت نام کاربر در اولین اجرا
- تقویم شمسی
- ورود / خروج / ورود و خروج
- انتخاب ساعت و دقیقه
- لیست اصلاحات شخصی
- تیک «اصلاح شد» و برگشت از تیک
- حذف رکورد

نحوه اتصال به تلگرام:
1) فایل‌های این پوشه را روی یک هاست استاتیک HTTPS مثل GitHub Pages یا Cloudflare Pages قرار بده.
2) URL نهایی مثل https://example.github.io/eslahat-dingi/ را بردار.
3) در BotFather، ربات خودت را انتخاب کن.
4) از /myapps یا تنظیم Main Mini App، یک Web App بساز و URL را وارد کن.
5) Main Mini App را برای ربات فعال کن تا دکمه Open App روی پروفایل ربات دیده شود.

مهم:
Bot Token را داخل index.html یا app.js قرار نده. برای این نسخه اصلاً به Token نیاز نیست.
